# 健康记录助手 — 使用手册

> 这是一个帮你记录每天饮食、血压、透析、用药等信息的小工具。
> 坚持记录，复诊时给医生看，沟通更高效。

---

## 怎么打开？

用手机或电脑浏览器，访问下面的地址：

```
http://localhost:7777
```

> 手机也能用！页面会自动适应屏幕大小。

---

## 页面说明

左边是导航栏，点不同的按钮进入不同页面。手机上点左上角的 **三横线** 按钮打开导航。

### 每日

| 页面 | 做什么用 |
|------|---------|
| **今日** | 看今天的总览：吃了多少、喝了多少水、体重、睡眠等 |
| **日志** | 查看过去所有的记录 |
| **趋势** | 看图表，了解营养和体重的变化趋势 |
| **报告** | 生成健康报告（复诊时给医生看） |
| **洞察** | 看数据之间的关联分析 |

### 临床（最重要）

| 页面 | 做什么用 | 什么时候用 |
|------|---------|-----------|
| **血压** | 记录每次量的血压 | 每天量完血压就记 |
| **透析** | 记录每次透析的情况 | 透析当天记录 |
| **疼痛** | 记录哪里疼、疼几分 | 不舒服的时候记 |
| **用药** | 管理正在吃的药 | 第一次使用时录入，之后查看 |
| **日记** | 记录今天的心情、精力、睡眠、食欲 | 每天睡前记一下 |

### 资料库

| 页面 | 做什么用 |
|------|---------|
| **食物** | 搜索和管理食物信息 |
| **食谱** | 管理自己常做的菜 |
| **批次** | 做了一大锅菜？记录份量，吃了就减 |

### 信号

| 页面 | 做什么用 |
|------|---------|
| **化验** | 查看化验结果和趋势 |
| **可穿戴** | 连接手环/手表，自动同步数据 |
| **目标** | 设置每天的营养目标 |

## 日常操作指南

### 1. 记录血压

1. 点左边 **血压**
2. 点 **记录血压** 按钮
3. 填入：
   - **收缩压**（高压）：如 130
   - **舒张压**（低压）：如 85
   - **脉搏**：如 72（可选）
4. 点 **保存**

> 下面有趋势图，可以看到最近血压变化。红色虚线是 120（正常上限），蓝色虚线是 80。

### 2. 记录透析

1. 点左边 **透析**
2. 点 **记录透析** 按钮
3. 填入：
   - **日期**：透析日期
   - **方式**：选 HD（血液透析）或 PD（腹膜透析）
   - **时长**：透析了多长时间（分钟）
   - **透前体重**：透析前称的体重
   - **透后体重**：透析后称的体重
   - **超滤量**：机器脱了多少水（毫升）
4. 点 **保存**

> 图表会显示体重和超滤量的趋势，紫色柱子是每次脱了多少水。

### 3. 记录疼痛

1. 点左边 **疼痛**
2. 点 **记录疼痛** 按钮
3. 填入：
   - **评分**：0 是不疼，10 是疼得受不了，选一个数字
   - **部位**：哪里疼
   - **类型**：选一种（酸痛/刺痛/胀痛等）
4. 点 **保存**

### 4. 记录每天的心情（日记）

1. 点左边 **日记**
2. 点 **写日记** 按钮
3. 给今天打几个分（1-5 分）：
   - 心情
   - 精力
   - 睡眠质量
   - 食欲
4. 可以写几句备注
5. 点 **保存**

### 5. 记录喝了多少水

1. 点 **今日** 页面
2. 找到 **水分** 区域
3. 点 **记录** 按钮
4. 填入喝了多少毫升

### 6. 记录体重

1. 点 **今日** 页面
2. 找到 **体重** 区域
3. 点 **记录** 按钮
4. 填入今天的体重（公斤）

## 复诊时怎么用？

### 生成健康报告

1. 点左边 **报告**
2. 选时间范围：
   - **7 天** — 最近一周
   - **14 天** — 最近两周
   - **30 天** — 最近一个月
3. 报告会自动生成，包含：
   - 每天平均吃了多少（热量、蛋白质、钾、钠等）
   - 血压趋势图和统计
   - 透析记录表
   - 疼痛评分图
   - 正在吃的药
   - 心情/精力变化
   - 体重变化
   - 最近的化验结果
4. 点右上角 **生成 PDF** 按钮
5. 在弹出的打印页面中，选择 **另存为 PDF**
6. 把 PDF 文件发给医生，或者打印出来带去复诊

> 报告一目了然，医生不用问就能看到你这段时间的情况。

## 每日提醒（建议）

养成习惯，每天固定时间做这些事：

| 时间 | 做什么 |
|------|--------|
| 早上起床 | 量血压 → 记录 |
| 三餐饭后 | 记录吃了什么 |
| 随时 | 喝水了就记录 |
| 透析当天 | 记录透析情况 |
| 不舒服时 | 记录疼痛 |
| 睡前 | 写日记（心情/精力/睡眠/食欲） |
| 每天同一时间 | 称体重 → 记录 |

## 常见问题

**Q：打不开页面？**
A：确认服务已启动，在浏览器地址栏输入 `http://localhost:7777`。

**Q：手机上能用吗？**
A：能！页面会自动适应手机屏幕。在手机上访问同样的地址即可。

**Q：数据存在哪里？**
A：存在你自己的电脑上，不会上传到任何云端。数据文件在 `~/.health-mcp/data.db`。

**Q：填错了怎么办？**
A：在对应的记录列表中，找到填错的那条，点 **编辑** 或 **删除** 按钮修改。

**Q：血压超过多少会有提醒？**
A：系统会自动监测——收缩压超过 160 或血钾超过 5.0 时，会通过钉钉发送告警消息。

**Q：每天会自动发报告吗？**
A：会！每天早上 8 点，系统会自动分析你的健康数据，生成摘要推送到钉钉群。

## 血压参考值

| 分类 | 收缩压（高压） | 舒张压（低压） |
|------|:---:|:---:|
| 正常 | < 120 | < 80 |
| 偏高 | 120-139 | 80-89 |
| 高血压 | 140-159 | 90-99 |
| 危险 | ≥ 160 | ≥ 100 |

> 如果经常高于 140/90，复诊时告诉医生。

## 疼痛评分参考

| 分数 | 含义 |
|:---:|------|
| 0 | 不疼 |
| 1-3 | 轻微疼痛，不影响日常 |
| 4-6 | 中度疼痛，有些影响 |
| 7-10 | 严重疼痛，难以忍受 |
